# Codex 剩余用量实施计划

## 1. 建立解决方案与领域模型

- 创建 .NET 10 WPF 应用、测试项目和最小目录结构。
- 实现一周窗口识别、剩余百分比换算、风险状态和新鲜度状态。
- 验证：边界值 `0`、`9`、`10`、`20`、`21`、`100` 的单元测试通过；无法识别周窗口时不返回伪造数据。

## 2. 接入 Codex app-server

- 自动发现 `codex.exe`，启动和关闭受控子进程。
- 完成协议初始化与 `account/rateLimits/read`、`account/usage/read` 请求。
- 从账号每日 Token bucket 汇总截至最新可用日期的连续 7 个自然日。
- 将响应映射为领域模型，不记录敏感响应。
- 验证：真实数据与 Codex 用量面板一致；使用伪 app-server 覆盖成功、超时、未登录、协议不兼容和进程退出场景。

## 3. 实现刷新与持久化

- 启动时立即刷新，之后按 1、5、10 分钟的用户设置刷新（默认 5 分钟）；支持手动和重复启动刷新。
- 只读解析本机 Codex JSONL 会话日志，按本机自然日累计 Token 增量。
- 串行化刷新请求，保存最后成功快照、窗口位置和自启设置。
- 验证：三项数据独立失败时分别显示最后成功值并标记过期；无历史值时显示不可用；重启后能恢复缓存、刷新间隔和位置。

## 4. 实现悬浮胶囊

- 实现透明、无边框、置顶、可拖动的收起与展开视图。
- 实现小、中、大三档整体尺寸并持久化用户选择。
- 实现四边和四角附着；展开或改变尺寸时保持附着并向屏幕内部增长。
- 实现风险颜色、过期视觉、系统主题跟随和本机时区的精确重置时间。
- 展开态显示一周进度条、账号近 7 日 Token、本机今日 Token、统计截止日期和完整数字提示。
- 实现右键菜单，不建立独立设置窗口。
- 验证：浅色/深色主题与 `100%`、`150%`、`200%` DPI 下清晰可读，三档尺寸可切换，拖动、点击和附着不冲突。

## 5. 实现 Windows 生命周期

- 实现单实例唤醒、当前用户开机自启、全屏隐藏、多显示器位置恢复。
- 验证：重复启动不产生第二个胶囊；重启后保留尺寸和附着位置；显示器拔插后迁移到最近的可用显示器边缘；真正全屏时隐藏，普通最大化时不隐藏。

## 6. 打包与验收

- 自包含发布 `win-x64` 主程序，并生成仅当前用户安装的 `CodexRemaining-Setup.exe`。
- 验证安装、覆盖升级、自启开关与卸载；卸载不删除用户日志和设置，除非用户明确选择清理。
- 在 Windows 10 22H2 x64 和 Windows 11 x64 上完成冒烟测试。

## 完成标准

- 胶囊展示的一周剩余百分比与 Codex 面板一致。
- 用量按选定的 1、5、10 分钟间隔自动更新，手动刷新可立即触发全部读取。
- Codex 客户端关闭时仍能刷新；缺失 Codex、未登录、断网或协议异常时不显示误导数据。
- 所有已确认的窗口、主题、位置、自启、隐私和安装行为均通过对应验证。
