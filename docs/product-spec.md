# Codex 剩余用量产品规格

## 目标

让用户无需打开 Codex 的用量面板，也能在 Windows 桌面上持续看到 Codex 一周用量窗口的状态。

## MVP 范围

- 仅支持当前 Windows 电脑上的单个、已登录 Codex 账号。
- 支持 x64 架构的 Windows 10 22H2 和 Windows 11，不承诺兼容更早的 Windows 10 版本或 ARM64。
- 展示 Codex 订阅的一周用量窗口、账号近 7 日 Token 和本机今日 Token，不展示 OpenAI API 余额。
- 通过本机 `codex app-server` 只读获取用量，不要求再次登录，不上传会话信息。
- 即使 Codex 桌面客户端未运行，悬浮软件也能独立显示和刷新用量。
- 默认随 Windows 登录自动启动，并允许通过右键菜单关闭自动启动。
- 仅允许单实例运行；重复启动时唤醒已有胶囊、确保其位于可见屏幕范围并立即刷新。
- 本机必须已安装并登录 Codex；有效的 `CODEX_EXECUTABLE` 显式路径具有最高优先级，否则软件优先使用 Codex App 内置的当前 `codex.exe`，找不到时再回退到 `PATH` 中的 CLI。
- 安装包不捆绑 Codex CLI，也不实现独立登录流程。

## 交付

- 产品显示名称为“Codex 剩余用量”，主程序名为 `CodexRemaining.exe`，安装包名为 `CodexRemaining-Setup.exe`。
- 最终交付为 `win-x64` 的 `Setup.exe` 安装包，而不是免安装绿色单文件。
- 安装器固定程序位置，配置标准卸载入口；安装后的主体程序为 `.exe`。
- 安装器仅为当前用户安装到 `%LOCALAPPDATA%\Programs\CodexRemaining`，无需管理员权限。
- 开机自启配置仅作用于当前 Windows 用户。
- 主程序采用 C#、.NET 10 和 WPF，并以自包含方式发布，目标电脑不要求预装 .NET Runtime。
- 不实现自动更新；升级时由用户手动运行新版 `Setup.exe` 覆盖安装。
- 个人 MVP 的安装包不做代码签名，允许 Windows SmartScreen 首次安装时显示“未知发布者”。

## 隐私与网络

- 除通过本机 Codex 集成刷新用量外，不接入其他外部服务。
- 不收集或上传遥测数据。
- 在 `%LOCALAPPDATA%\CodexRemaining\logs` 保留最近 7 天的本地滚动诊断日志。
- 日志只记录启动、刷新结果、错误类型和 Codex 版本，不记录登录令牌、账号邮箱或完整接口响应。

## 界面

- 使用可拖动、始终置顶的悬浮胶囊。
- 收起时保持 v0.1 的单行胶囊布局，只显示状态点和一周余额，例如 `周 95%`；重置卡详情仅在展开后展示。
- 点击后展开为紧凑信息卡，余量和重置倒计时同排展示，移除“每周限额”标题；重置卡数量与到期提示同排，Token 统计并排展示，刷新按钮和更新时间位于右上角，不为更新时间单独增加一行。辅助文字以 12 为基准，更新时间为 11.5；提高深色主题文字亮度，保证清晰可读，不提供趋势图、成本或请求数。
- 一周窗口与 ChatGPT 官方展示方向一致：进度条的状态色部分表示剩余比例（剩余 94% 时填充 94%），风险颜色仍由剩余百分比决定。
- 账号近 7 日 Token 截至账号侧最新可用日期，统计连续 7 个自然日；最新日期早于今天时同时显示截止日期。
- 本机今日 Token 统计当前电脑在本机时区当天 `00:00` 至当前时刻产生的新输入、缓存输入和输出 Token，只代表当前电脑。
- Token 主数值使用一位小数的中文紧凑单位（`万`、`亿`），鼠标悬停时显示带千位分隔符的完整数值。
- 重置时间显示为倒计时，例如 `6天18小时后重置`；不足一天显示小时和分钟，不足一分钟明确提示。悬停显示本机时区的准确重置时间。倒计时每 30 秒本地更新，不额外请求接口；到达重置时间后显示待刷新，不推断额度已恢复。
- 重置卡数量读取 `rateLimitResetCredits.availableCount`；根据可用卡的 `expiresAt` 展示最近到期倒计时，悬停显示本机时区的准确到期时间。仅展示，不消费重置卡。
- 重置卡数量缺失显示 `--`；数量为 0 显示暂无可用卡；只有数量或到期时间未知时明确显示未知。明细不完整时标记为“已知最早”，不假设已知明细覆盖全部卡。到达卡片到期时间后提示待刷新确认，不自行修改服务端数量。
- 自动刷新间隔支持 `1`、`5`、`10` 分钟，默认 `5` 分钟；修改后立即生效并在软件重启后保留。
- 展开视图提供手动刷新操作。
- 根据剩余用量改变胶囊颜色，不发送 Windows 系统通知。
  - 正常：剩余量大于 `20%`，使用蓝色。
  - 警告：剩余量为 `10%–20%`，使用橙色。
  - 危险：剩余量小于 `10%`，使用红色。
- 普通窗口（包括最大化窗口）上保持置顶；检测到真正的全屏应用时自动隐藏，退出全屏后恢复。
- 提供小、中、大三档胶囊尺寸；中档保持默认视觉基准，文字、间距和点击区域随档位整体调整，并在软件重启后保留选择。
- 悬浮胶囊拖动到当前显示器工作区的上、下、左、右边缘或四个角附近时自动附着，保持完全可见且不自动隐藏。
- 附着状态下展开或改变尺寸时，悬浮胶囊向屏幕内部增长。
- 保存悬浮胶囊最后位置；附着时同时保存显示器、边缘或角落及沿边位置，并在软件或 Windows 重启后恢复。
- 显示器断开或分辨率变化时，附着位置迁移到距离原显示器最近的可用显示器，并保持在当前可见工作区内。
- 左键单击胶囊时展开或收起详细状态；拖动胶囊时移动位置。
- 不提供独立设置窗口。右键菜单包含“立即刷新”“自动刷新间隔”“开机自启”“胶囊尺寸”“重置悬浮位置”和“退出”。
- “重置悬浮位置”将胶囊附着到主显示器右上角，同时保留当前胶囊尺寸。
- 自动跟随 Windows 浅色或深色主题，不提供手动主题设置。使用中性色细边框与克制阴影，额度风险通过状态点和进度条表示，展开卡片使用中性色细边框，收起胶囊保持 v0.1 的状态色描边。
- 正常、警告、危险和数据已过期状态在两种主题下都必须保持清晰可读。

## 异常状态

- 一周窗口、重置卡、账号近 7 日 Token 和本机今日 Token 独立保留刷新状态；单项读取失败时保留该项最后一次成功数据并单独标记“数据已过期”，不影响其他成功项。
- 断网、登录失效或读取失败时，保留对应的最后一次成功用量并明确标记“数据已过期”。
- 过期状态显示最后成功更新时间，并提供重试操作。
- 单项没有成功数据时显示“暂时无法获取”；只有全部数据项都不可用时才将整个面板视为不可用，不得将未知状态显示为 `0%`、`100%` 或 `0 Token`。
- 找不到 `codex.exe` 或 Codex 未登录时，明确说明缺失的前置条件并提供重试操作。
